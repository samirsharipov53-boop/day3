1. Создайте класс `Shop` с полем-списком `Products` типа `List<Product>`. Это поле будет хранить список товаров, доступных в магазине. 

2. Реализуйте методы для добавления товара в магазин, удаления товара из магазина и вывода списка товаров в магазине.                                    
    Для этого добавьте следующие методы в класс `Shop`:                                    
   
   - Метод `AddProduct`, который принимает объект типа `Product` в качестве аргумента и добавляет его в список `Products`.
  
   - Метод `RemoveProduct`, который принимает объект типа `Product` в качестве аргумента и удаляет его из списка `Products`.
  
   - Метод `PrintProductList`, который выводит на экран информацию о всех товарах в магазине.
   - Для этого переберите элементы списка `Products` и вызовите метод, который выводит информацию о каждом товаре.

4. Создайте классы `Phone` и `Car`, которые наследуют класс `Product`.                                            
 Класс `Product` должен иметь поля `Name` и `Price`, а классы `Phone` и `Car` должны расширять этот функционал своими дополнительными полями и методами.

5. Создайте объект класса `Shop` и добавьте несколько товаров различных типов                                                                       
    (несколько объектов класса `Phone` и несколько объектов класса `Car`) с помощью метода `AddProduct`.                                  

7. Продемонстрируйте работу методов класса `Shop` вызовом следующих операций:
  
   - Добавьте новый товар в магазин с помощью метода `AddProduct`.
  
   - Выведите список товаров в магазине с помощью метода `PrintProductList`.
  
   - Удалите один продукт с помощью метода `RemoveProduct`.

1. Класси `Shop` -ро бо майдони рӯйхат `Products` аз намуди `List<Product>` созед.                                                               
     Дар ин майдон рӯйхати маҳсулоти дар мағоза мавҷудбуда нигоҳ дошта мешавад.                                                                  

2. Татбиқи усулҳои илова кардани маҳсулот ба мағоза, удалить кардани маҳсулот аз мағоза ва намоиш додани рӯйхати маҳсулот дар мағоза.
     Барои ин усулҳои зеринро ба класси `Shop` илова кунед:
   
    - Усули `AddProduct`, ки объекти навъи `Product` ҳамчун параметр гирифта, ба рӯйхати `Products` илова мекунад.
  
    - Усули `RemoveProduct`, ки объекти навъи `Product` ҳамчун параметр гирифта, аз рӯйхати `Products` хориҷ мекунад.
  
    - Усули `PrintProductList`, ки маълумотро дар бораи ҳама маҳсулот дар мағоза нишон медиҳад.
    - Барои ин, элементҳои рӯйхати `Products` -ро такрор кунед ва усулеро даъват кунед, ки маълумотро дар бораи ҳар як маҳсулот нишон медиҳад.

4. Классҳои `Phone` ва `Car`-ро созед, ки аз синфи `Product` мерос мегиранд.
  Класси `Product` бояд майдонҳои `Name` ва `Price` дошта бошад ва классҳои `Phone` ва `Car` бояд ин функсияро бо майдонҳо ва усулҳои иловагии худ васеъ кунанд.

5. Объекти класси `Product`-ро созед ва якчанд маҳсулоти навъҳои гуногунро илова кунед
     (якчанд объекти класси `Phone` ва якчанд объекти класси `Car`) бо усули `AddProduct`.

7. Амалиёти методҳои класси `Shop`-ро бо даъвати амалҳои зерин нишон диҳед:
  
    - Бо усули `AddProduct` ба мағоза маҳсулоти нав илова кунед.
  
    - Рӯйхати маҳсулоти дар мағозаро бо истифода аз усули `PrintProductList` намоиш диҳед.
  
    - Яке аз маҳсулотро ба воситаи методи `RemoveProduct` удалит кунед.
